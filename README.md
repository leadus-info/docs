## 理念
Leadus Projectの理念は[こちら](./MANIFEST.md)をご覧ください。

## 科目の一覧
Leadus Projectの科目・接頭辞と、各科目のリポジトリの一覧は[こちら](./SUBJECTS.md)をご覧ください。

## ライセンス
Leadus Projectの成果物は、全てリポジトリ単位でライセンスを定めます。\
各リポジトリの`LICENSE`をご確認ください。

本リポジトリの[ライセンス](./LICENSE)は、本リポジトリの文書(マニフェスト・貢献の手順・コントリビューションガイド等)そのものに適用されます。\
各科目リポジトリの記事には、各科目リポジトリの`LICENSE`(CC BY-SA 4.0)が適用されます。

## 貢献の流れ
Leadus Projectに参加し、コンテンツの改善・アップデートにご協力いただける方は、[こちら](./contribution/README.md)をご覧ください。

## docsと科目リポジトリの役割分担
全科目に共通する文書は本リポジトリで管理し、科目リポジトリからは本リポジトリへリンクします。科目リポジトリには、科目ごとに異なるものだけを置きます。

| 管理場所 | 管理するもの |
| --- | --- |
| docs(本リポジトリ) | [マニフェスト](./MANIFEST.md)、[貢献の手順](./contribution/WORKFLOW.md)、[コントリビューションガイド](./contribution/CONTRIBUTING.md)(全科目共通の執筆ルール)、[科目の一覧](./SUBJECTS.md)、この役割分担 |
| 科目リポジトリ | `LICENSE`、`GUID.md`(科目固有の執筆ルール)、記事。`README.md`・`CONTRIBUTING.md`は本リポジトリへの案内のみを書く |

- 共通の内容を科目リポジトリに複製しないでください。複製すると、改訂時に内容が食い違う原因になります。
- 科目リポジトリを新設するときは、[科目の一覧](./SUBJECTS.md)にリポジトリのURLを記載してください。
