# 参考資料インデックス(society科目)

このディレクトリ(`references/society/`)は、`society`科目(社会・地理歴史・公民)の学習指導要領インデックスである。
格納方針の全体像は[../README.md](../README.md)を参照。

出典: 文部科学省 学習指導要領(小学校:平成29年告示 / 中学校:平成29年告示 / 高等学校:平成30年告示)。
原本PDFは <https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm> および各校種の解説編ページ
(小学校: 1387014.htm / 中学校: 1387016.htm / 高等学校: 1407074.htm)で公開されている。

**校種間で科目構成が変わる点に注意**: 小学校・中学校では「社会」という1教科だが、高等学校では
「地理歴史」(地理総合・地理探究・歴史総合・日本史探究・世界史探究)と「公民」(公共・倫理・政治経済)の
2教科に分かれる。本サイトのadvanced記事を比較する際は、扱うトピックに応じて地理歴史/公民どちらの
参考資料を見るか判断すること。

### 高等学校学習指導要領_公民.txt(法令本体・公民の節のみ抜粋)
「公共」「倫理」の見出しはPDFレイアウトの都合で1文字ずつ改行分割されることがある
(例:「公」「共」が離れた行に出る)ため、`grep`は緩めに検索すること。

| 科目 | 開始行(目安) |
|---|---|
| 公共 | 33付近(見出しが分割されている) |
| 倫理 | 401付近(見出しが分割されている) |

### 小学校学習指導要領_解説_社会編.txt / 中学校学習指導要領_解説_社会編.txt / 高等学校学習指導要領_解説_地理歴史編.txt / 高等学校学習指導要領_解説_公民編.txt
文部科学省が発行する解説編をそのまま収録。法令本体より遥かに詳しく、各内容の指導のねらい・扱う範囲・
指導順序の考え方・具体例が記述されている。**網羅性や学習順序を検討する際はこちらを主に参照する。**
冒頭に目次があるので、まず目次で対象学年・分野・科目のページを確認し、`grep -n`でそのページ番号や
見出し語を検索して該当箇所に当たるとよい。ファイルが大きいため、全文をReadせず`grep`で絞り込んでから
該当範囲だけ`Read`すること。

## stage ↔ 校種・科目・参照ファイルの対応

| 本サイトのstage | 対応する校種・科目 | 主に参照するファイル |
|---|---|---|
| beginner | 小学校・社会(第3〜6学年) | 小学校学習指導要領_社会.txt、小学校学習指導要領_解説_社会編.txt |
| intermediate | 中学校・社会(地理的/歴史的/公民的分野) | 中学校学習指導要領_社会.txt、中学校学習指導要領_解説_社会編.txt |
| advanced | 高等学校・地理歴史 or 公民(トピックに応じて判断) | 高等学校学習指導要領_地理歴史.txt / _公民.txt、対応する解説編 |
| bachelor / master | 対応する学習指導要領なし(大学レベル) | 比較対象外 |

本サイトの記事`subject`と、学習指導要領側の領域名・科目名は名称が完全一致しないため、機械的な文字列一致ではなく、
扱っているトピックの内容で対応付けること。
