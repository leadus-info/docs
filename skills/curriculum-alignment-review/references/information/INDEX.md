# 参考資料インデックス(information科目)

このディレクトリ(`references/information/`)は、`information`科目(情報)の学習指導要領インデックスである。
格納方針の全体像は[../README.md](../README.md)を参照。

出典: 文部科学省 学習指導要領(高等学校:平成30年告示)。
原本PDFは <https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm> および高等学校解説編ページ
(1407074.htm)で公開されている。

**重要な注意点**: 「情報」は独立教科として高等学校にのみ存在する。小学校・中学校には対応する
独立教科がなく、小学校では各教科等の中で情報活用能力の育成として、中学校では「技術・家庭」の
技術分野内の内容「Ｄ 情報の技術」として部分的に扱われるのみで、独立した学習指導要領・解説編は
存在しない。そのため、`beginner`/`intermediate`のinformation記事については、このスキルは
比較対象の学習指導要領が存在しない旨を伝え、`advanced`(高等学校 情報Ⅰ・情報Ⅱ)のみを比較対象とする。

### 高等学校学習指導要領_解説_情報編.txt
文部科学省が発行する解説編をそのまま収録。法令本体より遥かに詳しく、各内容の指導のねらい・扱う範囲・
指導順序の考え方・具体例が記述されている。**網羅性や学習順序を検討する際はこちらを主に参照する。**
冒頭に目次があるので、まず目次で対象科目のページを確認し、`grep -n`でそのページ番号や見出し語を
検索して該当箇所に当たるとよい。

## stage ↔ 校種・科目・参照ファイルの対応

| 本サイトのstage | 対応する校種・科目 | 主に参照するファイル |
|---|---|---|
| beginner | 対応する独立教科の学習指導要領なし | 比較対象外 |
| intermediate | 対応する独立教科の学習指導要領なし(技術・家庭の一部に含まれるのみ) | 比較対象外 |
| advanced | 高等学校・情報(情報Ⅰ・情報Ⅱ) | 高等学校学習指導要領_情報.txt、高等学校学習指導要領_解説_情報編.txt |
| bachelor / master | 対応する学習指導要領なし(大学レベル) | 比較対象外 |
