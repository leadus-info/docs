# 学習指導要領との整合性レビュー

科目記事(現状は`math`のみ。将来的に他科目が追加される想定)が、文部科学省の学習指導要領と比べて
「網羅的か」「構成・学習順序・前提関係がおかしくないか」を確認する。
学習指導要領はあくまで**参考資料**であり、本サイトの理念(`MANIFEST.md`)や執筆方針(`CONTRIBUTING.md`)が優先される。
そのため、このスキルは**差異を検出してレポートするところまで**を担当し、記事の実際の編集は行わない。

## 0. 対象リポジトリ・対象科目を確認する

このスキルはユーザー共通(`~/.claude/skills/`)に配置されているため、他のプロジェクトで作業中でも
一覧に出てくる。実行前に以下を確認する。

1. カレントのリポジトリルートに`MANIFEST.md`と`CONTRIBUTING.md`が存在するか。存在しなければ、
   このスキルが想定する知識サイトリポジトリではないと判断し、その旨を伝えて何もせず終了する。
2. ユーザーの依頼から対象科目(リポジトリルート直下のディレクトリ名。例: `math`)を特定する。
   科目名が明示されていない場合、リポジトリルート直下で`beginner`等のstageディレクトリを持つ
   ディレクトリを探して候補を挙げ、曖昧なら確認する。
3. 対象科目に対応する参考資料が`references/<科目>/`にあるか確認する(下記1.参照)。
   複数科目にまたがる依頼で一部の科目に参考資料がない場合は、その科目分だけ対象外として伝え、
   参考資料がある科目については通常どおり続行する。対象が参考資料未整備の科目のみであれば、
   その旨を伝えて終了する。

## 1. 参照資料について

`references/<科目>/`配下に、その科目の学習指導要領をテキスト抽出したものを格納する構成になっている。
現状`references/math/`(算数・数学)、`references/science/`(理科: 物理・化学・生物・地学)、
`references/society/`(社会・地理歴史・公民)、`references/information/`(情報。高校のみ)が整備済み
(math/science/societyは小学校・中学校・高等学校の法令本体の該当節および教科別解説編、informationは
高等学校のみ)。
ファイル一覧・行番号インデックスは各科目の`references/<科目>/INDEX.md`を参照(全体の格納方針は
[references/README.md](references/README.md))。

- ファイルサイズが大きいため、全文をReadせず`grep -n`で見出しやキーワードを検索してから該当範囲だけ`Read`すること。
- stageと校種の対応、記事の`subject`フィールドと学習指導要領側の領域名の対応関係も、各科目の`INDEX.md`にまとめてある。
- `bachelor`/`master`(大学レベル)は、mathの場合は対応する学習指導要領が存在しないため比較対象外
  (他科目でも大学レベルの学習指導要領は通常存在しない)。

## 2. 対象範囲を確定する

ユーザーの依頼から、対象となる「stage × subject」(例: `math`科目の`intermediate`の`代数`)、
または個別記事のパスを特定する。曖昧な場合(「全部見て」等、広すぎる)は、対象範囲をAskUserQuestion
などで確認する。

対象が決まったら、該当ディレクトリ配下の記事を洗い出す:

```
<科目>/<stage>/<subject-dir>/*.md
```

- 記事フロントマターの`subject`(日本語)とディレクトリ名の対応は固定でないため、各記事のフロントマターの
  `subject`値で照合する。
- 併せて `<科目>/<stage>/index.md` を読み、そのstageで公式にどう章立て(H3のまとまり)されているかを把握する。
- 各記事の`requires`(前提記事)も収集し、記事間の前提関係グラフを把握する。

## 3. 対応する学習指導要領の範囲を特定する

`references/<科目>/INDEX.md`のstage対応表に従い、参照すべきファイルと行範囲を絞り込む。
法令本体で学年・領域ごとの範囲を掴み、詳細な指導内容・順序の考え方は解説編で補う。

## 4. 突き合わせて確認する観点

### 網羅性(抜け漏れ)
対象subject×stageの記事群全体で、学習指導要領がその学年・科目で扱うとしている内容が
記事として存在するか確認する。存在しない場合、それが「意図的に別stageで扱っている」のか
「単純に抜けている」のかを、他stageの記事一覧やrequiresも見て判断する。

### 学習順序
- 記事の`requires`が示す前提関係が、学習指導要領の学年進行・単元の前後関係と大きく矛盾していないか。
- 同一stage内でのトピックの提示順序(index.mdのH3の並び)が、指導要領の一般的な指導順序と大きくズレていないか。

### 構成・内容
- ある内容が学習指導要領の想定より明らかに上位/下位のstageで扱われていないか(例: 指導要領で中学校範囲の内容が
  advanced記事にしか存在しない、逆に高校範囲の内容がintermediateで扱われている、など)。
- CONTRIBUTING.mdの難易度別方針(初級編は形式的定義を避ける、発展編は証明を完全に扱う、等)と矛盾しない範囲で、
  学習指導要領が示す「その学年で扱ってよい厳密さ・範囲」を逸脱していないか。

### 到達目標(ゴール)の整合性
学習指導要領は、学年・分野・科目ごとの「目標」見出しの下に、資質・能力の三つの柱
(⑴知識及び技能、⑵思考力・判断力・表現力等、⑶学びに向かう力・人間性等)で到達目標を定めており、
さらに各内容(単元)の中にも「ア(理解すること・技能)」「イ(考察し、表現すること)」という、
その単元で「何ができるようになっていないといけないか」を示す、より粒度の細かい記述がある。
これらは`grep -n`で「目標」やア/イの項目本文(キーワード)を検索すると見つけやすい。

記事のフロントマターの`goal`(読者が到達すべきゴール)を、対応する学習指導要領の目標・ア/イの記述と突き合わせ、
次の観点で確認する。
- 記事の`goal`が、指導要領がそのstageで要求する到達点(知識・技能だけでなく、考察・表現できることまで)を
  満たしているか。知識の暗記に留まり、「考察する」「表現する」に相当する記述が欠けていないか。
- 逆に、指導要領の到達点を超えた(より上位stageで初めて求められる)水準を`goal`が要求していないか。
- `goal`の文言が曖昧で、指導要領が示す到達点との対応関係が判断できない場合は、その旨を指摘する
  (`goal`自体を明確化する提案を含めてよい)。

いずれの観点も、学習指導要領との差異=即「誤り」ではない。本サイトは学習指導要領に縛られない独自の理念
(`MANIFEST.md`)を持つため、差異は「検討材料」として提示する。

## 5. 出力形式

差異を検出したら、以下の形式でレポートする(ファイルへの書き込みは行わない):

```
## 監査対象: <科目> / <stage> / <subject> (<対象記事数>本)
参照した学習指導要領: <ファイル名:行範囲 の一覧>

### 網羅性
- [対象記事あり/なし] <指導要領上のトピック> — <根拠となる記述の要約と出典(ファイル名:行番号)>
  → 提案: ...

### 学習順序・前提関係
- <記事A> は <記事B> を前提としているが、学習指導要領では逆順(または同時)に扱われている — <出典>
  → 提案: ...

### 構成・内容
- <該当箇所> — <指導要領との差異> — <出典>
  → 提案: ...

### 到達目標(ゴール)の整合性
- <記事> の`goal`「<記事のgoal文言>」— <指導要領の目標/ア・イとの差異(不足/超過/曖昧)> — <出典>
  → 提案: ...

### 学習指導要領の範囲外だが問題ない点
(本サイト独自の理念上、意図的に指導要領と異なると考えられる箇所があれば、誤検出でないことの確認としてここに記載)
```

各指摘には必ず出典(ファイル名と行番号または見出し)を添える。出典を示せない推測は指摘に含めない。

## 6. 差異への対応

このスキルは差異の提示までを行う。検出した差異それぞれについて、実際に記事を修正するかどうかは
ユーザーが個別に判断・指示する。ユーザーから明示的に「この指摘を反映して」と指示されない限り、
記事ファイルを編集しない。
