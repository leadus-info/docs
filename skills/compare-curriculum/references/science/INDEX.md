# 参考資料インデックス(science科目)

このディレクトリ(`references/science/`)は、`science`科目(理科: 物理・化学・生物・地学)の学習指導要領インデックスである。
格納方針の全体像は[../README.md](../README.md)を参照。

出典: 文部科学省 学習指導要領(小学校:平成29年告示 / 中学校:平成29年告示 / 高等学校:平成30年告示)。
原本PDFは <https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm> および各校種の解説編ページ
(小学校: 1387014.htm / 中学校: 1387016.htm / 高等学校: 1407074.htm)で公開されている。

### 小学校学習指導要領_解説_理科編.txt / 中学校学習指導要領_解説_理科編.txt / 高等学校学習指導要領_解説_理科編.txt
文部科学省が発行する解説編をそのまま収録。法令本体より遥かに詳しく、各内容の指導のねらい・扱う範囲・
指導順序の考え方・具体例が記述されている。**網羅性や学習順序を検討する際はこちらを主に参照する。**

- 小学校解説は学年別(第3〜6学年)。
- 中学校解説は`[第1分野]`/`[第2分野]`別。
- 高等学校解説は「理科編・理数編」の合本で、理科側は
  科学と人間生活 → 物理基礎 → 物理 → 化学基礎 → 化学 → 生物基礎 → 生物 → 地学基礎 → 地学 の順に
  節が並ぶ(理数側の節は理科より後ろにあるため、理科の内容を探す分には無視してよい)。

冒頭に目次があるので、まず目次で対象学年・分野・科目のページを確認し、`grep -n`でそのページ番号や
見出し語(例:「第４学年」「エネルギー」)を検索して該当箇所に当たるとよい。ファイルが大きいため、
全文をReadせず`grep`で絞り込んでから該当範囲だけ`Read`すること。

## stage ↔ 校種・科目・参照ファイルの対応

| 本サイトのstage | 対応する校種・科目 | 主に参照するファイル |
|---|---|---|
| beginner | 小学校・理科(第3〜6学年) | 小学校学習指導要領_理科.txt、小学校学習指導要領_解説_理科編.txt |
| intermediate | 中学校・理科(第1分野・第2分野) | 中学校学習指導要領_理科.txt、中学校学習指導要領_解説_理科編.txt |
| advanced | 高等学校・理科(科学と人間生活/物理基礎/物理/化学基礎/化学/生物基礎/生物/地学基礎/地学) | 高等学校学習指導要領_理科.txt、高等学校学習指導要領_解説_理科編.txt |
| bachelor / master | 対応する学習指導要領なし(大学レベル) | 比較対象外 |

本サイトの記事`subject`と、学習指導要領側の領域名・科目名は名称が完全一致しないため、機械的な文字列一致ではなく、
扱っているトピックの内容で対応付けること。特に高校理科は「基礎科目」と「本科目」で扱う範囲・厳密さが
大きく異なる(基礎科目は概論的、本科目はより専門的・定量的)ため、記事がどちらの水準を想定しているかを
意識して比較すること。
