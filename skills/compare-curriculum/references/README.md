# 参考資料の構成

このスキルが対象とする各科目の学習指導要領は、科目ごとに `references/<科目ディレクトリ名>/` として格納する。
`<科目ディレクトリ名>` は、対象リポジトリのルート直下にある科目ディレクトリ名(例: `math`)と一致させる。

```
references/
  math/
    INDEX.md            # math科目の参考資料インデックス(ファイル一覧・行番号・stage対応表)
    *.txt                # 学習指導要領(法令本体・解説編)のテキスト抽出
  science/
    INDEX.md            # science科目(理科: 物理・化学・生物・地学)の参考資料インデックス
    *.txt
  society/
    INDEX.md            # society科目(社会・地理歴史・公民)の参考資料インデックス
    *.txt
  information/
    INDEX.md            # information科目(情報。高校のみ)の参考資料インデックス
    *.txt
  <他科目>/              # 将来、国語などを追加する場合はここに同様の構成で追加する
    INDEX.md
    *.txt
```

現状、参考資料が整備済みなのは `math` `science` `society` `information` の4科目。
`information`(情報)は高等学校にのみ独立教科として存在するため、小学校・中学校の参考資料はない
(詳細は[information/INDEX.md](information/INDEX.md))。

## 出典

学習指導要領・解説編の原本PDFは文部科学省サイトで公開されている。
一覧ページ: <https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm>
(校種別の解説編一覧は、上記ページからリンクされる小学校/中学校/高等学校それぞれの解説ページを参照)。
`mext.go.jp` ドメインはユーザーから今後無条件でアクセスしてよいと承認済み。

## 新しい科目の参考資料を追加する手順

1. 対象科目の学習指導要領・解説編PDFを上記の文部科学省サイトから入手する。
2. `pdftotext -layout`(解説編など単一科目の文書)、または法令本体のように他教科を含む文書であれば
   該当科目の節だけを行範囲で切り出してから、`references/<科目ディレクトリ名>/` にテキストとして保存する。
3. `references/<科目ディレクトリ名>/INDEX.md` を作成し、`references/math/INDEX.md` や
   `references/science/INDEX.md` と同じ形式(ファイル一覧・学年/単元ごとの行番号インデックス・
   stageと校種の対応表)でまとめる。
4. 対応する参考資料が存在しない科目の記事についてこのスキルが呼ばれた場合、
   対応する `references/<科目ディレクトリ名>/` が存在しなければ、その科目の参考資料が未整備であることを
   ユーザーに伝え、比較は行わない。
