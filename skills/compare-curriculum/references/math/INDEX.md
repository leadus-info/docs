# 参考資料インデックス（math科目）

このディレクトリ(`references/math/`)は、`math/`科目(算数・数学)の学習指導要領インデックスである。
他科目を追加する場合は`references/<科目ディレクトリ名>/`として並べる(詳細は[../README.md](../README.md))。

文部科学省の学習指導要領（算数・数学関連部分）をPDFからテキスト抽出したものを格納している。
元のPDFは対象科目（国語・社会・理科…）を含む大部部な文書のため、`_算数.txt` / `_数学.txt` という名前のファイルは
算数・数学の節だけを切り出したもの、`_解説_*編.txt` という名前のファイルは文部科学省が別冊として発行している
教科別の解説編（元から算数・数学に特化した文書）をそのまま収録したものである。

出典: 文部科学省 学習指導要領（小学校:平成29年告示 / 中学校:平成29年告示 / 高等学校:平成30年告示）。
原本PDFは本スキルには同梱していない（各校種の学習指導要領・解説はいずれも文部科学省サイトで公開されている）。

### 小学校学習指導要領_解説_算数編.txt / 中学校学習指導要領_解説_数学編.txt / 高等学校学習指導要領_解説_数学編.txt
文部科学省が発行する解説編をそのまま収録。法令本体より遥かに詳しく、各内容の指導のねらい・扱う範囲・
指導順序の考え方・具体例が記述されている。**網羅性や学習順序を検討する際はこちらを主に参照する。**
冒頭に目次があるので、まず目次で対象学年・領域のページを確認し、`grep -n` でそのページ番号や見出し語
（例：「第４学年」「文字を用いた式」）を検索して該当箇所に当たるとよい。ファイルが大きいため、
全文をReadせず`grep`で絞り込んでから該当範囲だけ`Read`すること。

## stage ↔ 校種・参照ファイルの対応

| 本サイトのstage | 対応する校種・科目 | 主に参照するファイル |
|---|---|---|
| beginner | 小学校・算数 | 小学校学習指導要領_算数.txt、小学校学習指導要領_解説_算数編.txt |
| intermediate | 中学校・数学 | 中学校学習指導要領_数学.txt、中学校学習指導要領_解説_数学編.txt |
| advanced | 高等学校・数学（数学Ⅰ・Ⅱ・Ⅲ・Ａ・Ｂ・Ｃ） | 高等学校学習指導要領_数学.txt、高等学校学習指導要領_解説_数学編.txt |
| bachelor / master | 対応する学習指導要領なし（大学レベル） | 比較対象外 |

本サイトの`subject`（数・代数・幾何・関数・確率・解析・基礎・具体的な関数・線形代数）と、
学習指導要領側の領域名（Ａ数と計算／Ａ数と式、Ｂ図形、Ｃ測定／Ｃ変化と関係／Ｃ関数、Ｄデータの活用、
高校の科目区分）は名称が完全一致しないため、機械的な文字列一致ではなく、扱っているトピックの内容で対応付けること。
